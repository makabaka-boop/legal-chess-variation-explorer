# 国际象棋变例板

TypeScript + Svelte 实现的离线标准国际象棋变例分析板。从初始局面出发，点击走子，
随时回到任意祖先节点另走一支形成变例，最多支持 200 个节点。
无 AI、无棋钟、无棋谱文本解析，运行时不发起任何网络请求。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 产出静态文件到 dist/（离线可用）
npm run preview  # 预览构建产物
npm test         # 全部测试（含 chess.js 对照）
npm run check    # svelte-check 类型检查
```

## 规则引擎（自研，`src/lib/chess/`，不依赖任何棋类库）

- `movegen.ts`：攻击检测 → 伪合法走子 → 以“走后己方王是否被攻击”过滤出合法走子。
  - 王安全：所有走法（含吃过路兵）都实际执行后验王；
  - 王车易位：权利、空格、王当前格/经过格/落点不被攻击；
  - 吃过路兵：先真正移除被吃的兵再验王，因此“两兵离队暴露横线将”判非法；
  - 升变：抵达底线生成 后/车/象/马 四种走法。
- `key.ts`：三次重复判定的局面键 = 棋子布局 + 行棋方 + 易位权 + **当前真正合法**的
  过路兵机会。仅有目标格但因王暴露等原因吃不了过路兵时，键中不含该格，
  不产生额外局面身份。
- `san.ts`：标准代数记谱（含消歧、`+`/`#`），用于展示。

## 变例树（`src/lib/game/tree.ts`）

每个节点保存走完该步后的完整局面；节点的轮次、易位权、过路兵机会都由其祖先路径
重放得到，重复次数也只沿“根 → 当前节点”路径统计——兄弟变例的历史互不泄漏。
重复走已存在的走法只跳转不新建节点；节点总数达 200 后拒绝新建并提示。

## 交互（`src/lib/game/controller.ts` + `src/lib/components/`）

- 点击棋子显示合法落点（空位圆点 / 吃子圆环），再点落点走子；
- 升变弹出选择框：**确认前走法不提交，取消不会在树上留下幽灵子节点**；
- 状态栏显示行棋方、将军、将死、逼和、三次重复可申领状态（不处理其他和棋条件）；
- 侧栏“合法后续”列出当前节点全部合法走法（SAN），点击即走；已存在于树中的走法高亮；
- 变例树支持点击任意节点跳转，回退后另走一子即成分支；←/→ 键前后导航。

## 测试（`tests/`）

- `perft.test.ts`：标准 perft 基准（初始局面、Kiwipete、过路兵/升变专项位置）；
- `engine.test.ts`：过路兵移除导致的透线将军、易位经过受攻击格、角上车被吃、
  过路兵局面键、将死/逼和/升变；
- `tree.test.ts`：分支回退后的状态隔离（轮次/易位权/过路兵/重复次数）、
  200 节点上限、已存在走法跳转、删除分支；
- `controller.test.ts`：升变确认/取消无幽灵节点、点选交互；
- `crosscheck.test.ts`：以独立棋类库 chess.js 作对照（仅测试使用）——
  指定局面两层深 + 30 盘随机对局，逐步比对合法走法集合、SAN 与将军/将死/逼和判定。
